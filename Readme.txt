# Black Panthers — Single-file Flask App

Minimal Flask demo of the “Black Panthers” site.  
Single-file app `black_panthers.py` creates `static/img` automatically. Drop your images into `static/img`.

## Requirements
- Python 3.8+
- pip

## Install
```bash
python -m venv venv
source venv/bin/activate   # macOS / Linux
venv\Scripts\activate      # Windows PowerShell
pip install flask
